# Allam-Macleod — study pages

`index.html` — interactive deep-neck-space atlas (retropharyngeal + parapharyngeal):
layered SVG cross-sections, extent/spread chart, boundaries, differentials, imaging
guide and a 12-question self-test. Plates live in `assets/`.

View locally: `python3 -m http.server 8000` → http://localhost:8000/
